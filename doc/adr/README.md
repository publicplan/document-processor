# Architecture Decision Records

Dieses Verzeichnis enthält Architecture Decision Records (ADRs) für wesentliche Architekturentscheidungen im `document-processor`.

ADRs dokumentieren **was** entschieden wurde, **warum**, und welche Konsequenzen sich daraus ergeben. Sie werden nicht rückwirkend geändert; supersedierte Entscheidungen erhalten den Status `Superseded` und einen Verweis auf den nachfolgenden ADR.
